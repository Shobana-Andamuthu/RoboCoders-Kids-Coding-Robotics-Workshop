Ages 6 - 10: Creative Logic

Scratch Visual Block Coding

Our Scratch path introduces primary school children to logic workflows. Since they do not have to write code lines, they focus on structural concepts such as loops, conditional events, and variable parameters by snapping colorful graphics together.

Learn basic coordinates & direction variables
Build custom platformer games & visual animations
Earn the Scratch Novice Digital Certificate

Ages 11 - 14: Text Engineering

Python Game Development

Transition children to typed syntax. Kids write actual script lines using Python. They build games like Snake and Pong, learning object structures, libraries, and functions in the process.

Understand Python fundamentals (arrays, loops, variables)
Program algorithmic systems and game collision boundaries
Unlock the online Python Code Sandbox editor
Explore Curriculum
Ages 10 - 14: Hardware Engineering

Hands-On Robotics & Sensors

Unite code syntax with physical electronics. Students learn to wire custom motors, infrared sensor arrays, and sonar devices to program robots that navigate obstacle grids autonomously.

Wire breadboards, LED signals, and gear motors
Program obstacle detection with sonar ultrasonic rangefinders
Prepare for international kids STEM robotics contests
