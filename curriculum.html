Class Progression Map

Our Academic Roadmap

A gamified pathway designed to build programming confidence, hardware logic, and sensor integration skills step-by-step.

Level 1: Foundations Visual Logic Loops
Level 2: Systems Circuit Hardware & Sensors
Level 3: Languages Python Automation & AI

Junior Coder Curriculum

Focuses on visual block programming. Children develop spatial recognition, coordinate grids, basic loops, and sprite event controls by building story games.

01

Grid Coordinates

Positioning sprites along X/Y grids using direction buttons.

02

Simple Loops

Writing repeat actions to cycle animations without code bloating.

Intermediate Builder Curriculum

Introduces microcontrollers and mechanical robots. Kids wire light sensors, program servo motors, and program small vehicles to run autonomously.

01

Breadboards & Circuits

Wiring LED bulbs, switches, and analog resistors safely.

02

Sensor Inputs

Program conditional scripts to react to ultrasonic sound ranges.

Senior Developer Curriculum

Transition to professional syntax writing. Teenagers master Python, data arrays, function methods, and program smart city systems.

01

Python Syntax

Learning standard definitions, variable declarations, loops, and objects.

02

API Integration

Hooking custom apps to cloud servers to store statistics.

Teaching Philosophy

Project-Based Learning (PBL)

We don't teach programming through dry syntax slides. Children start every lesson with a concrete target — like landing a digital rocket or building a smart plant sensor — and learn coding concepts by implementing the solution step-by-step.

This cycle builds resilience as students learn that mistakes and script errors are just steps towards optimization.
